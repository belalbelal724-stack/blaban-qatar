# 🥛 ب لبن قطر — نظام إدارة التشغيل

نظام إدارة تشغيل لسلسلة فروع ب لبن في قطر. تطبيق PWA يعمل بدون اتصال بالإنترنت.

## 🚀 النشر

### Vercel
```bash
vercel --prod
```
أو ارفع الملف على [vercel.com/new](https://vercel.com/new)

### GitHub Pages
1. ارفع المجلد على repository
2. Settings → Pages → Source: main branch → Save

## 📋 الملفات
- `index.html` — التطبيق كاملاً (single-file)
- `service-worker.js` — للعمل offline
- `manifest.json` — إعدادات PWA
- `icon-*.png` — أيقونات التطبيق
